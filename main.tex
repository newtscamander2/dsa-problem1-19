\section*{Our solution}
To start with we want to prove that $s = n^2$.

From the pseudo code we can see that $i$ a incrementing sum which we can write as $\sum_{0}^{n}1$. $s$ is also a incrementing sum of $i$ which can be written as $s = \sum_{i=0}^{n}i$.

$s$ is at the end of our program set to $s = s + s - n$, which we can write as
$$s_n = 2\sum_{i=0}^{n}i - n$$
From the mathematics cheats sheet in the supplementary notes we know that $\sum_{i=1}^{n}i = \frac{n(n+1)}{2}$.

We can therefore write
$$s_n = 2\frac{n(n+1)}{2}-n$$
Which we can easily simplify even further
$$s_n = n(n+1) -n$$
$$s_n = n^2 + n - n$$
$$s_n = n^2$$

Which is proof that $s = n^2$.

One easy loop invariant we can see is that $i$ is initialized as $0$. Therefore we can set the loop invariant $0 \leq i$. From the proof of $s = n^2$ we know that $i = \sum_{0}^{n}1=n$. We can therefore also say that $i \leq n$. We can prove these loop invariants with induction.

Loop invariant:

\begin{equation}
	I(s_n): 0 \leq i \leq n \land 0 \leq s \leq \sum_{i=0}^{n}i
\end{equation}
