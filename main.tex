\section*{Our solution}
To start with we want to prove that $s = n^2$.

From the pseudo code we can see that $i$ a incrementing sum which we can write as $\sum_{0}^{n}1$. $s$ is also a incrementing sum of $i$ which can be written as $s = \sum_{f=0}^{n}f$.

$s$ is at the end of our program set to $s = s + s - n$, which we can write as
$$s_n = 2\sum_{f=0}^{n}f - n$$
From the mathematics cheats sheet in the supplementary notes we know that $\sum_{i=1}^{n}i = \frac{n(n+1)}{2}$.

We can therefore write
$$s_n = 2\frac{n(n+1)}{2}-n$$
Which we can easily simplify even further
$$s_n = n(n+1) -n$$
$$s_n = n^2 + n - n$$
$$s_n = n^2$$

Which is proof that $s = n^2$.

One easy loop invariant we can see is that $i$ is initialized as $0$. Therefore we can set the loop invariant $0 \leq i$. From the proof of $s = n^2$ we know that $i = \sum_{0}^{n}1=n$. We can therefore also say that $i \leq n$.

The loop invariant for the given loop is therefore

\begin{equation}
	I(S_i): 0 \leq i \leq n \land 0 \leq s \leq \sum_{f=0}^{n}f
\end{equation}

\vspace{5mm}
\textbf{Proof by induction}
Base case $n=1$:
$i=0, s = 0, n \geq 0$
Let $S_{i}$ represent the state of the while-loop at a given iteration $i$ thus $S_0$ will be the first iteration of the while-loop after the proceeding code has executed.
To prove the loop invariant $I$ using proof by induction\dots

For the basecase (which is the start of our loop) we can verify $0 \leq i \leq n$ which becomes $0 \leq 0 \leq 0$ which is true. We can also verify $0 \leq s \leq \sum_{f=0}^{n}f$ which becomes $0 \leq 0 \leq 0$ since if $n=0$ (which is a possibility since $n\geq0$ is the only requirement for $n$) then $\sum_{f=0}^{n}f = 0$.
Our loop invariant therefor holds for the start of our loop. 

We now assume that our loop invariant $I(S_i)$ holds for $i$.
$$0 \leq i \leq n \land 0 \leq s \leq \sum_{i=0}^{n}i \rightarrow 0 \leq i+1 \leq n \land 0 \leq s+i \leq \sum_{f=0}^{n}f$$
